# Project 4: Streamgraph Dashboard

## Overview
This project visualizes monthly and cumulative app installs across categories using an interactive streamgraph. It also explores monthly growth and identifies unusual changes in install trends.

## Tools Used
Python, Pandas, NumPy, Plotly, and Jupyter Notebook.
